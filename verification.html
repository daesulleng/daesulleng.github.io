가입과 별개인 선택 인증

학생증과 비바톤 인증은 나중에 진행할 수 있습니다. 둘 중 하나만 완료하거나 건너뛰어도 일반 서비스를 이용할 수 있습니다. 맛개팅 참여에는 두 인증이 모두 필요합니다.

학생증 승인과 그린 체크마크

학생증 인증은 가입 마지막 단계 또는 맛개팅 이용 인증에서 선택할 수 있습니다. 별도 동의 후 학생증 이미지와 학교·이름·학번·사진을 관리자가 대조합니다. 생년월일이 표시된 경우 가입 정보와 대조할 수 있으나 학생증 확인은 성인인증을 대신하지 않습니다. 주민등록번호 전체·주소·바코드·QR·금융정보는 가려 주세요. 승인 후 닉네임 옆 그린 체크마크와 마이페이지에 학교 소속 확인 상태가 표시됩니다. 배지는 공인 본인확인·현재 재학 또는 상대방의 안전을 보장하지 않습니다. 원본은 심사 완료 후 삭제하며 승인·반려 결과, 확인 시각·담당자·검토 사유·대조 정보와 동의 버전은 탈퇴 처리까지 보관합니다. 학교·학번·실명 변경 시 재확인이 필요합니다. 인증을 거부해도 일반 서비스를 이용할 수 있으며 배지와 맛개팅 이용은 제한됩니다.

블록체인 익명 인증과 저장 범위

비바톤은 블록체인 기반 익명 인증을 통해 성인 여부를 전달합니다. 대슐랭가이드는 비바톤 인증에 사용한 이름·주민등록번호·비밀번호 원문을 받거나 저장하지 않습니다. 다만 만 19세 이상 확인 결과, 중복 인증 방지를 위한 서비스별 식별자의 SHA-256 해시, 인증·동의 시각과 버전은 Supabase에 탈퇴 처리까지 보관합니다. 가입 시 별도로 입력한 실명·생년월일은 회원정보로 보관됩니다. 따라서 모든 개인정보나 인증 기록이 어디에도 남지 않는다는 의미는 아닙니다. 비바톤의 자체 회원정보·접속기록 처리는 제공사 개인정보처리방침(https://www.bbaton.com/privacy/)을 따릅니다. 인증 코드는 Oracle Cloud Infrastructure 일본 도쿄 서버를 거쳐 HTTPS로 처리하고, 토큰·원본 응답은 중계 중 메모리에서만 사용하며 지속 저장하지 않습니다. 결과와 해시는 Supabase 미국 동부 서버에 저장됩니다. 해당 기능의 수집·이용과 국외 처리에 각각 동의한 경우만 진행합니다. 거부·철회 시 맛개팅 이용만 제한됩니다. 문의·철회: daesulleng@gmail.com, 비바톤: help@bbaton.com, Supabase: privacy@supabase.com, Oracle: https://www.oracle.com/legal/privacy/privacy-policy.html.

카테고리 추천 → 마음 전하기 → 채팅 → 약속 → 종료

맛개팅은 만 19세 이상이며 비바톤 성인인증과 학생증 학교 소속 확인을 완료한 회원이 이용합니다. 가입 시 직접 입력한 성별을 그대로 사용하며 이 성별은 공인 확인 기관이 검증한 정보가 아닙니다. 성별은 앱에서 임의 변경할 수 없고 잘못된 정보 정정은 고객지원으로 요청할 수 있습니다. 음식 카테고리 1~3개 중 하나 이상이 겹치는 이성 회원을 학교·연령·모임 조건 안에서 추천합니다. 후보 열람은 무료이고 새로운 매칭 요청 성공 시 50P를 사용합니다. 수락을 보장하지 않으며 거절·취소 시 포인트를 돌려주지 않습니다. 기존 기준대로 72시간 미응답 만료 시에는 50P를 한 번 환급합니다. 중복 재전송에는 추가 차감하지 않습니다. 수락 후 채팅에서 등록 가게를 선택하거나 서로 상의한 장소를 직접 입력하고 날짜·시간을 제안합니다. 상대방이 확인해야 약속이 확정되고 변경 시 다시 확인해야 합니다. 약속 시간이 지난 뒤 양쪽의 만남 완료 확인으로 종료합니다. 포인트는 활동으로 적립하며 현금 결제·환전·양도를 제공하지 않습니다. 2:2·3:3 모임 대표자는 동행인의 만 19세 이상 여부와 참여 동의를 확인해야 합니다.

맛개팅 채팅과 첨부 사진

맛개팅 대화와 승인된 첨부 사진은 매칭이 진행 중인 두 회원에게 표시됩니다. 새 첨부 사진은 상대방에게 표시되기 전에 전체 관리자가 안전 검수를 위해 열람할 수 있습니다. 사진 검수만으로 전체 대화 내용을 관리자에게 자동 공개하지는 않습니다. 신고 처리 또는 법령상 필요한 접근은 정당한 목적과 필요한 범위로 제한합니다. 매칭 종료·취소·차단 시 메시지와 대화 내역은 즉시 삭제되고 사진 접근도 차단됩니다. 첨부 사진 원본은 서버 삭제 대기열에 넣고 1분 주기로 처리하며 실패 시 재시도합니다. 실제 완료는 서버·저장소 상태에 따라 늦어질 수 있습니다. 미전송 임시 사진은 24시간 후 삭제 대상으로 처리합니다. 전송된 검수 대기 사진은 최대 7일 후 자동 반려·삭제 대상으로 처리합니다. 기기에 이미 저장한 사진이나 수신된 푸시는 회수할 수 없습니다. 신고 사유·대상·처리 기록은 신고 대응 목적에 따라 별도로 처리하며 전체 대화를 자동 복사해 보관하지 않습니다. 푸시에는 대화 내용·사진·실명을 넣지 않고 새 메시지 도착 사실만 알립니다.
